School Management System
About the Project
The School Management System is a web-based application developed using Laravel. It helps manage school records and information efficiently.

Features
Student Management
Teacher Management
Subject Management
Class Management
User Registration and Login
Dashboard
Technologies Used
Laravel
PHP
MySQL
HTML
CSS
JavaScript
Bootstrap
Installation
Clone the repository.
Run composer install.
Copy .env.example and rename the copy to .env.
Run php artisan key:generate.
Configure your database in .env.
Run php artisan migrate.
Start the server using php artisan serve.
